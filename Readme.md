# Reusados

**Used Video Game Marketplace**  
Jul 2022 – Sep 2024

Reusados was a PHP-based marketplace focused on video game collectibles.  
The project went through multiple iterations and was developed as a real product, from idea to monetization.

## Overview

- Built and iterated multiple versions of a marketplace focused on video game collectibles.
- Integrated the official MercadoLibre API (search endpoints, OAuth token refresh via cron jobs, automated listings management).
- Developed a custom admin panel with role-based access, dynamic pagination, responsive UI, and centralized error logging.
- The platform generated steady income and validated the product model before API policy changes restricted certain operations.

This project significantly strengthened my understanding of third-party API integration, automation workflows, and operating a real product under platform constraints.
